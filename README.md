# KickUnblock

An iPhone app to watch Kick: lives with chat, multi-view, channel VODs and clips,
search, categories, followed channels and go-live notifications. English by default,
French when the iPhone is in French (or chosen in Settings).

## Install

Add the source `https://raw.githubusercontent.com/MXFia19/KickUnblock/main/apps.json`
in AltStore, SideStore or Feather, or download `KickUnblock.ipa` from the latest
release. Every push to `main` that changes the app publishes a new build there.

## Features

- **Live**: the most watched lives (language filter, 18+ filter), your followed channels
  that are live, and the channels you watched recently.
- **Player**: iOS player (fullscreen, Picture in Picture that keeps playing when you leave
  the screen, AirPlay, VOD speed), landscape with the chat on the side, live viewers and
  title refreshed every minute, live duration, "stream ended" notice, sleep timer,
  maximum quality, VODs resumed where you stopped, share and open on kick.com.
- **Chat**: latest messages refreshed every 3 s, emotes, badges (broadcaster, moderator,
  VIP, subscriber…), replies, optional timestamps, text size, "latest messages" button
  when you scroll up, and a button to hide it.
- **Multi-view**: up to 4 lives side by side; tap one to hear it.
- **Channels**: banner, live card, VODs (with progress), clips (top all time, month,
  week, today, or most recent), About (bio, socials, recent categories), follow.
- **Browse and search**: categories (with a filter) and their lives; channel and
  category search.
- **Following**: kept on the iPhone, live ones first; notifications when a followed
  channel goes live (checked in the background when iOS allows it).

## How it reads Kick

- Data: kick.com's API (`/stream/livestreams`, `/api/v2/channels/…`, `/api/search`,
  `/api/v1/subcategories`, chat history), with plain requests from the app (URLSession
  and its User-Agent) — it doesn't pretend to be a browser or the Kick app.
- Video: the iOS player reads Kick's HLS streams directly (Amazon IVS for lives,
  `stream.kick.com` for VODs, `clips.kick.com` for clips).
- Chat: read-only, from the public chat history (Kick no longer uses its old Pusher
  connection for live chat).

If Kick refuses the app's requests, it shows "Kick refused the app's requests
(error 403)".

## Development

- Code: `Sources/` (SwiftUI, iOS 16+), project generated by XcodeGen (`project.yml`).
- Texts: English keys in the code, French in `Sources/Localization.swift`.
- Build: `.github/workflows/build.yml` (unsigned IPA, release `build-N`, source
  `apps.json`); `Changelog:` lines in commit messages become the release notes.
- `worker/`: experimental Cloudflare Worker (API and stream relay for a website), not
  used by the app.
